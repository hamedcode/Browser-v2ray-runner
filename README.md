# Browser v2ray Runner

اجرای کانفیگ‌های `vless://` و `trojan://` فقط داخل مرورگر (کروم/اج/فایرفاکس روی ویندوز)، بدون اینکه روی کل سیستم اثر بذاره.

## معماری

- **extension/** — اکستنشن مرورگر (Manifest V3). مدیریت لینک‌ها، دکمه اتصال/قطع، تنظیم پروکسی مرورگر.
- **native-host/** — سورس Go یک برنامه کوچیک (`v2ray-ext-host.exe`, حدود ۲ مگابایت) که با پروتکل Native Messaging به اکستنشن وصل می‌شه و پروسه‌ی **sing-box** رو مدیریت می‌کنه.
- **installer/** — اسکریپت نصب که هستِ محلی رو کپی می‌کنه، آخرین نسخه‌ی رسمی sing-box رو از گیت‌هاب دانلود می‌کنه، و Native Messaging Host رو تو رجیستری ویندوز (فقط HKCU — بدون نیاز به دسترسی ادمین) ثبت می‌کنه.

چرا sing-box؟ یه باینری تک‌فایلی رسمی، فعال نگه‌داری می‌شه، و از vless/trojan (با ws/grpc/tls/reality) پشتیبانی می‌کنه — سبک‌تر و ساده‌تر از vendor کردن xray-core.

## نصب (روی ویندوز)

### ۱. نصب هستِ محلی
از این نسخه به بعد، همه‌چی تو **یه فایل تکی** جمع شده: `installer/install.bat`. کافیه همین یه فایل رو دانلود کنی و دابل‌کلیکش کنی — نیازی به اکسترکت کردن یا نگه‌داشتن فایل‌های کناریش نیست.

این فایل یه ترفند شناخته‌شده استفاده می‌کنه: خودش هم یه batch عادیه، هم یه اسکریپت PowerShell کامل رو زیر یه مارکر داخل خودش نگه می‌داره؛ موقع اجرا، بخش PowerShellِ خودش رو (با `more`) تو یه فایل موقت استخراج می‌کنه و اجراش می‌کنه. مانیفست‌های JSON هم دیگه فایل جدا نیستن، مستقیم داخل همون اسکریپت PowerShell به‌صورت متن (here-string) نوشته شدن.

تنها چیزهایی که واقعاً از اینترنت دانلود می‌شن، دو تا باینری‌ان: `v2ray-ext-host.exe` (از یه GitHub Release خودت) و `sing-box.exe` (از ریلیز رسمی `SagerNet/sing-box`) — هردو با **ورژن‌چک** (اگه از قبل همون ورژن نصب باشه، رد می‌شه؛ `-Force` برای نصب اجباری دوباره) و هردو با یه **تاییدیه‌ی ترکیبی واحد**: قبل از دانلود، اسم دقیق و حجم (مگابایت) هرکدوم رو با هم نشون می‌ده و منتظر Y/N می‌مونه. اگه نه بزنی، بدون تغییر دیگه‌ای متوقف می‌شه (exit code 2 که `install.bat` جدا از خطای واقعی رنگ زرد نشونش می‌ده، در مقابل قرمز برای خطا و سبز برای موفقیت).

این اسکریپت فایل‌ها رو تو `%LOCALAPPDATA%\V2rayExtHost` می‌ذاره و برای کروم، اج، و فایرفاکس (هرکدوم که نصب باشه) رجیستری رو ست می‌کنه. نیاز به دسترسی ادمین نداره چون فقط `HKCU` (per-user) دستکاری می‌شه.

> ویندوز ممکنه SmartScreen رو برای `v2ray-ext-host.exe` نشون بده چون امضا نشده؛ خودِ `install.bat` امضا نداره ولی چون اسکریپت متنیه (نه exe) و همه‌ی دانلودهاش از GitHub با تاییدِ کاربره (نه یه بلوک base64 مبهم که موقع اجرا decode بشه)، ریسک flag شدنش به‌مراتب کمتر از یه exe یا یه دراپر معمولیه.

> **قبل از استفاده: باید `native-host/` رو کامپایل کنی، `v2ray-ext-host.exe` رو به‌عنوان asset یه GitHub Release (تو ریپازیتوری خودت) آپلود کنی، و مقدار `$HostBinaryRepo` تو `installer/install.bat` (نزدیک بالای بخش PowerShell، بعد از مارکر `__PS1_BOUNDARY__`) رو با `username/repo` واقعیت جایگزین کنی.**

### راه‌اندازی خودکار (صفحه‌ی onboarding)
از نسخه‌ی فعلی، اولین باری که اکستنشن نصب می‌شه (`chrome.runtime.onInstalled`، reason=`install`)، یه تب جدید با `onboarding.html` خودش باز می‌شه: یه ویزارد ۳ مرحله‌ای (خوش‌آمد+انتخاب زبان → بررسی/دانلود → پایان). مرحله‌ی دوم اول یه چک سریع می‌زنه؛ اگه هستِ محلی از قبل وصل بود مستقیم پیام موفقیت رو نشون می‌ده، وگرنه لینک دانلود `install.bat` رو نشون می‌ده و هر ۲.۵ ثانیه با پیام `checkNativeHost` از background.js می‌پرسه که آیا هستِ محلی وصل شده یا نه (بدون نیاز به روشن بودن sing-box — فقط چک می‌کنه که native host پاسخ بده).

> **قبل از پابلیش: در `extension/onboarding.js` و `extension-firefox/onboarding.js` مقدار `INSTALLER_DOWNLOAD_URL` رو به آدرس واقعیِ همین `install.bat` (مثلاً یه لینک `raw.githubusercontent.com` یا یه GitHub Release asset) عوض کن. فروشگاه‌های اکستنشن اجازه نمی‌دن باینری native host داخل بسته‌ی خودِ اکستنشن باشه، پس این فایل باید جدا میزبانی بشه.**

### درباره‌ی انتشار
Chrome Web Store برای انتشار هزینه‌ی یک‌بار ۵ دلاری داره؛ Firefox Add-ons (AMO) و Microsoft Edge Add-ons هر دو رایگانن. یه راه ترکیبی معقول:
- **کاربران فایرفاکس:** اکستنشن رو از AMO نصب می‌کنن، بعد فقط `install.bat` رو از گیت‌هاب دانلود می‌کنن (یه فایل، نه یه پوشه)
- **کاربران کروم/اج:** کل ریپازیتوری رو از گیت‌هاب می‌گیرن و طبق بخش «۲. بارگذاری اکستنشن در کروم/اج» به‌صورت Load unpacked نصب می‌کنن (یا اگه انتشار روی Edge Add-ons هم انجام بشه، از همون‌جا هم قابل نصبه)

### ۲. بارگذاری اکستنشن در کروم/اج
1. برو به `chrome://extensions` (یا `edge://extensions`)
2. «حالت توسعه‌دهنده» رو فعال کن
3. «Load unpacked» → پوشه‌ی `extension/` رو انتخاب کن

شناسه‌ی اکستنشن از قبل با یه کلید ثابت pin شده (تو `manifest.json`)، پس همیشه همون ID رو می‌گیره که تو `installer/com.v2rayext.host.chrome.json` ثبت شده — نیازی به تنظیم دستی نیست.

### ۳. بارگذاری اکستنشن در فایرفاکس
پوشه‌ی جدا `extension-firefox/` تو زیپ هست — همون کد اکستنشنه، فقط manifest.json ازش از قبل مخصوص فایرفاکسه (نیازی به کپی/جایگزین کردن دستی نیست، که رایج‌ترین علت شکست بارگذاریه: اگه manifest مخصوص کروم رو با service_worker به فایرفاکس بدی، بارگذاری میشکنه).

1. برو به `about:debugging#/runtime/this-firefox` → «Load Temporary Add-on»
2. مستقیم فایل `extension-firefox/manifest.json` رو انتخاب کن (نه پوشه‌ی `extension/`)

اگه هنوز خطا می‌گیری، تو همون صفحه‌ی `about:debugging` پیام خطا رو نگه دار/عکس بگیر — دقیقاً بگه کجای manifest رد شده.

(برای نصب دائمی روی فایرفاکس معمولی، اکستنشن باید امضای Mozilla بگیره؛ «Load Temporary Add-on» برای تست و استفاده‌ی شخصی روی هر بار باز شدن فایرفاکس نیاز به بارگذاری مجدد داره — برای استفاده‌ی دائم گزینه‌ی مناسب Firefox Developer/Nightly با `xpinstall.signatures.required=false` یا ساخت یه `.xpi` امضاشده است.)

### ۴. استفاده
- روی آیکون اکستنشن کلیک کن
- لینک `vless://...` یا `trojan://...` رو بچسبون و «افزودن» بزن
- روی «اتصال» بزن — فقط ترافیک همون مرورگر از پروکسی محلی (`127.0.0.1:2080` که sing-box بالا می‌آره) عبور می‌کنه

## قابلیت‌های نسخه‌ی فعلی
- **پروتکل‌های پشتیبانی‌شده**: vless، vmess (فرمت base64 JSON استاندارد v2rayN)، trojan، shadowsocks (`ss://` — بدون plugin)، و socks5 (`socks5://`، با یا بدون احراز هویت) — همه با همون هستِ sing-box، بدون نیاز به هسته‌ی جدا
- **دو زبانه**: پیش‌فرض انگلیسی، از تب «Settings» قابل تغییر به فارسی
- **افزودن یکپارچه و هوشمند**: یه کادر واحد — یه لینک، چند لینک، یا یه لینک اشتراک؛ خودش تشخیص می‌ده. خط‌های خالی/کامنت بی‌سروصدا رد می‌شن
- **تب «Subs»**: مدیریت لینک‌های اشتراک با «Update»/«Remove» جدا برای هرکدوم — یه اشتراک پیش‌فرض («Top 100 (port-based)»، از ریپازیتوری `port-based-v2ray-configs`) هم موقع اولین نصب خودکار اضافه می‌شه؛ دقیقاً مثل بقیه‌ی اشتراک‌ها قابل rename/حذفه، هیچ فرقی با یه اشتراک دستی نداره
- **مصرف اینترنت زنده** و **آی‌پی خروجی خودکار بعد از اتصال** (با چند تلاش با تأخیر، چون sing-box یه لحظه طول می‌کشه پورت رو باز کنه) — با پرچم کشور (روی ویندوزهای قدیمی‌تر که فونت emoji پرچم‌های ترکیبی رو ساپورت نمی‌کنه، به‌جاش یه بج تمیز با کد دو-حرفی کشور نشون داده می‌شه)
- **آیکون اکستنشن پویا**: آبی = قطع، سبز = متصل
- **پرچم کشور واقعی**: به‌جای تکیه به فونت emoji (که رو خیلی از سیستم‌های ویندوز پرچم رو درست نشون نمی‌ده)، از یه عکس پرچم کوچیک استفاده می‌شه — هم کنار آی‌پی خروجی، هم داخل اسم کانفیگ‌هایی که تو ریمارکشون پرچم دارن
- **مرتب‌سازی کانفیگ‌ها**: از یه منوی کشویی بالای لیست — بر اساس تازه‌ترین افزوده‌شده، کمترین پینگ، یا الفبایی
- **اسم‌گذاری اشتراک‌ها**: موقع افزودن می‌تونی یه اسم دلخواه بذاری؛ هر وقت خواستی هم با دکمه‌ی ✎ می‌تونی اسمش رو عوض کنی — دیگه قاطی نمی‌شن
- **تست پینگ هم‌زمان تا ۱۰ کانفیگ**: هرکدوم روی پورت جدا، بدون تداخل؛ نتایج بین باز/بسته کردن پاپ‌آپ ذخیره می‌مونن؛ کانفیگ ناموفق فقط «-1» قرمز نشون می‌ده (خطای کامل با نگه‌داشتن ماوس)
- **حذف کانفیگ‌های ناسالم / حذف همه**
- **۶ رنگ تم قابل انتخاب** از تب Settings

> به‌خاطر بررسی آی‌پی، اشتراک، آمار مصرف، و عکس پرچم‌ها (از flagcdn.com)، این نسخه `host_permissions` برای همه‌ی آدرس‌های http/https می‌خواد.

## محدودیت‌های شناخته‌شده
- لینک‌های `ss://` با plugin (مثل v2ray-plugin یا obfs) پشتیبانی نمی‌شن — نیاز به باینری پلاگین جدا دارن که این نسخه vendor نکرده
- لینک‌های خام `http://` به‌عنوان پراکسی HTTP مستقیم قابل افزودن نیستن، چون همون فرمت رشته‌ای دقیقاً با یه URL اشتراک یکسانه و راهی برای تشخیص خودکار قصد کاربر نیست؛ کادر افزودن هر `http(s)://` رو به‌عنوان لینک اشتراک در نظر می‌گیره. برای پراکسی SOCKS5 مستقیم از `socks5://` استفاده کن (این فرمت مبهم نیست)
- انتشار رسمی تو Chrome Web Store / addons.mozilla.org نیازمند بازبینی جداگانه‌ست؛ استورها نسبت به اکستنشن‌هایی که کاربر رو به نصب یه فایل اجرایی خارجی هدایت می‌کنن حساسن.
- فایرفاکس بدون امضا فقط به‌صورت موقت (Temporary Add-on) بارگذاری می‌شه.
- در نسخه‌ی فعلی فقط یک کانفیگ هم‌زمان می‌تونه فعال باشه (سوییچ بین کانفیگ‌ها = قطع و اتصال دوباره).
